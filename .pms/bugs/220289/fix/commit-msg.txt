fix: prevent browser crash on long video playback

1. Root cause: background.js registered onHeadersReceived listener
   with "<all_urls>" including "media" type, intercepting every
   streaming video segment request and accumulating console.log
   output and request processing overhead over 12-24h
2. Fix: remove "media" from SUPPORT_REQUEST_TYPE_ARRAY so streaming
   media requests bypass download interception; convert
   SUPPORT_MEDIA_EXT_ARRAY to Set for O(1) lookup; remove per-request
   console.log in onBeforeSendHeaders; fix QTimer memory leak in
   sendUrlToDownloader with deleteLater; add 5000ms timeout to
   waitForFinished in runPipeProcess
3. Impact: normal file downloads still intercepted; streaming video
   playback no longer triggers download extension overhead; reduced
   memory accumulation during long browser sessions

Log: Fix browser crash during long video playback by excluding media requests from download interception

Influence:
1. Test normal file downloads (exe, zip, mp4) are still intercepted
2. Test online video playback does not trigger download interception
3. Test long-running browser session memory stability

fix: 修复浏览器长时间播放视频崩溃问题

1. 根因：background.js 的 onHeadersReceived 监听器使用
   "<all_urls>" 且 SUPPORT_REQUEST_TYPE_ARRAY 包含 "media" 类型，
   拦截每个流媒体视频分段请求，12-24小时累积 console.log 输出和
   请求处理开销导致浏览器崩溃或界面卡死
2. 方案：从 SUPPORT_REQUEST_TYPE_ARRAY 移除 "media" 使流媒体请求
   绕过下载拦截；将 SUPPORT_MEDIA_EXT_ARRAY 转为 Set 实现 O(1) 查找；
   移除 onBeforeSendHeaders 中逐请求 console.log；修复
   sendUrlToDownloader 中 QTimer 内存泄漏添加 deleteLater；
   为 runPipeProcess 的 waitForFinished 添加 5000ms 超时
3. 影响：正常文件下载仍被拦截；流媒体视频播放不再触发下载扩展
   开销；减少浏览器长时间运行内存累积

Log: 修复浏览器长时间播放视频崩溃问题，流媒体请求不再被下载拦截

Influence:
1. 测试正常文件下载（exe、zip、mp4）仍能被下载器接管
2. 测试在线视频播放不触发下载拦截
3. 测试浏览器长时间运行内存稳定性
